# SHIVAM ENTERPRISE — WhatsApp QR Integration & PDF Document Sharing

## PROJECT OBJECTIVE

Implement a complete WhatsApp integration module in the existing SHIVAM ENTERPRISE Business Management System.

The user must be able to connect their existing WhatsApp account by scanning a QR code, similar to WhatsApp Web.

After connecting, users must be able to send genuine PDF documents generated by the ERP directly to any WhatsApp mobile number.

**Primary requirement:** No Meta API key, no paid WhatsApp Cloud API and no third-party paid messaging provider.

Use the Node.js `whatsapp-web.js` library with QR-code authentication, subject to its current compatibility, terms and account-risk limitations.

This is an unofficial WhatsApp Web integration. Display a clear warning in the UI that WhatsApp may restrict accounts using unofficial automation. Do not bypass CAPTCHA, account verification, rate limits or other WhatsApp security controls.
